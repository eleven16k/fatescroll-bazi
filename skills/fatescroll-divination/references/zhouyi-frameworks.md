# 从《周易》六十四卦经文蒸馏的8个可执行分析框架

> 来源：周易 Skill (github.com/qbdx-hub/zhouyi-skill)。用法：按用户问题匹配触发词，只读取并运用命中的 1-2 个框架，勿整篇注入。

## 框架 1：处境诊断

**触发词**：处境、局面、像什么卦、哪一卦、现在处境、局面类型、先诊断

**要旨**：把用户现实问题映射到1-3个候选卦象簇，输出中心张力、危险误判、下一步该调用的skill

**方法论**：《周易》的第一层用法是“处境命名”：不要急着给行动建议，先判断问题属于哪类局面。屯是开局混乱，蒙是认知未开，需是等待，讼是争端，师是组织化动员，比是结盟，泰是否极通塞，剥是基础剥落，复是返回正轨，困是受阻，革是改革，鼎是新秩序承载，既济是已成后的尾部风险，未济是未成前的临门风险。

这个 skill 把用户的现实问题映射到 1-3 个候选卦象簇，输出“中心张力、危险误判、下一步该调用的 skill”。它不宣布未来，而是帮助用户把混沌问题放进一个可讨论的结构。

**执行步骤**：

1. **收集处境事实**
   - 完成标准：列出目标、压力来源、参与者、资源、已发生变化、用户当前想采取的动作。
2. **匹配候选卦象簇**
   - 完成标准：给出 1-3 个候选处境，例如开局难、等待、争端、联盟、闭塞、剥落、修复、改革、完成前后风险。
3. **抽取中心张力**
   - 完成标准：说明局面真正矛盾是什么，例如“秩序未立却想推进”“争端可处理但不能拖到底”“基础剥落不宜扩张”。
4. **输出诊断卡**
   - 完成标准：包含候选卦象、证据、最危险误判、建议下一步调用的 skill、以及不确定性。

**适用边界**：- 用户要求随机起卦、预测彩票、断定婚姻生死或给确定未来。
- 用户只需要原文翻译，不需要处境分析。
- 用户面对法律、医疗、财务高风险问题却要求替代专业意见。

## 框架 2：时位判断

**触发词**：该不该动、到时候、时机、阶段、第几爻、初爻、上爻、过早、临门

**要旨**：判断一件事处在初二三四五上哪个阶段，匹配行动强度，给出换位条件

**方法论**：《周易》的六爻可以提炼成一个时位诊断表。同一目标，在不同位置上的建议不同：初位多是萌芽和根部，二位开始进入稳定互动，三位靠近门槛、容易冒进，四位接近外部或上位、需要承接，五位是核心权责位，上位是末端、过盛或完成后的反转点。

行动是否正确，不只看“做什么”，还看“现在处在哪个位置”。乾卦把力量从潜伏、显现、警惕、跃迁、飞腾到亢进完整展开；渐卦把推进写成逐步迁移；既济、未济则提醒完成前后都有尾部风险。

**执行步骤**：

1. **确定当前阶段**
   - 完成标准：把用户处境放入初、二、三、四、五、上之一，并说明依据。
2. **判断位置风险**
   - 完成标准：指出主要风险是过早、门槛冒进、承接不足、高位责任、末端过度还是尾部风险。
3. **匹配行动强度**
   - 完成标准：给出适合当前阶段的动作，例如蓄势、试探、求助、承接、主导、收束。
4. **给出换位条件**
   - 完成标准：说明什么证据出现后，才算进入下一阶段。

**适用边界**：- 用户要完整起卦、变卦、占筮算法。
- 用户只问某个卦名是什么意思，不涉及阶段。
- 用户要求确定日期或精确预测结果。

## 框架 3：进退边界

**触发词**：该进、该退、利有攸往、涉大川、勿用、无攸利、征凶、推进还是暂停

**要旨**：把用户想做的动作分成进、涉险、守、待、退五档，根据边界词给出行动许可或禁令

**方法论**：《周易》的行动词不是情绪建议，而是边界条件。“利有攸往”表示有方向地推进可行；“无攸利”表示没有值得推进的方向；“勿用”表示某类动作暂时不要启用；“利涉大川”表示可以承担重大障碍或转换；“不利涉大川”表示不宜把问题升级为大动作；“征凶”表示主动出征会带来结构性危险。

这个 skill 把用户想做的动作分成五档：进、涉险、守、待、退。然后根据处境、时位、资源、关系和风险词，给出行动许可或禁令。

**执行步骤**：

1. **写出用户想做的动作**
   - 完成标准：把动作表述为推进、涉险、守成、等待、退回、修复、求助之一。
2. **匹配边界词**
   - 完成标准：选出最相关的词组：利有攸往、利涉大川、无攸利、勿用、不利涉大川、征凶、居贞吉。
3. **检查许可条件**
   - 完成标准：说明许可条件是否满足，包括秩序、信任、资源、阶段、外部支持。
4. **给出行动分档**
   - 完成标准：输出“可做 / 小做 / 等待 / 先修复 / 不做 / 退出”，并列出下一步最小动作。

**适用边界**：- 用户要求确定未来结果，而不是行动边界。
- 高风险法律、医疗、投资问题没有专业信息。
- 用户只想看原文释义，不需要决策建议。

## 框架 4：吉凶翻译

**触发词**：吉、凶、悔、吝、无咎、厉、贞、亨、孚、风险、悔亡

**要旨**：把周易判断词翻译成现代风险等级、成因、补救动作、剩余不确定性

**方法论**：《周易》的吉凶词可以提炼成风险等级，而不是简单“好/坏”。吉是条件匹配下可行；凶是结构危险；悔是已有偏差但可补救；吝是局促、羞困、损耗；无咎是责任风险可控但不等于收益；厉是危险存在，需要警戒；贞是守正和持续；亨是通达；孚是可信承诺。

这个 skill 的核心动作是：把古文判断词翻译成“风险等级、成因、补救动作、剩余不确定性”。

**执行步骤**：

1. **识别判断词**
   - 完成标准：列出原文里的吉、凶、悔、吝、无咎、厉、贞、亨、孚等词。
2. **翻译风险等级**
   - 完成标准：把每个词转为现代含义：可行、危险、可补救、局促、责任可控、需警戒、需守正、可通达、需信任。
3. **绑定条件**
   - 完成标准：说明该判断成立的条件，例如有孚、居贞、利见大人、不可大事。
4. **给出补救或禁令**
   - 完成标准：如果是悔/吝/厉/凶，输出可补救动作或必须避免的动作。

**适用边界**：- 用户只要求统计字频。
- 用户要求把吉凶当作确定预言。
- 用户需要完整训诂考证或版本校勘。

## 框架 5：过盛检查

**触发词**：亢龙有悔、过头、该收、成功后、大壮、丰盛、既济、加码、太顺

**要旨**：检查是否从可进变成该收、从主导变成压迫、从丰盛变成遮蔽、从既济变成终乱

**方法论**：《周易》反复提醒：强不等于可以继续强推，高位不等于无风险，成功不等于结束。过盛的危险来自三种错觉：以为力量越大越好，以为高位可以不收束，以为已经完成就不用戒备。

这个 skill 专门检查“成功后的风险”：是否已经从可进变成该收，从主导变成压迫，从丰盛变成遮蔽，从既济变成终乱。

**执行步骤**：

1. **识别过盛信号**
   - 完成标准：列出权力、资源、速度、情绪、承诺、舆论中哪些已经过高。
2. **检查卡点**
   - 完成标准：指出可能像“触藩”的边界：制度、现金流、团队承载、关系反弹、合规风险。
3. **判断是否该收**
   - 完成标准：给出继续推进、降速、分权、复盘、止盈、退出或暂停的建议。
4. **设计谦抑动作**
   - 完成标准：给出一个可以立刻降低过盛风险的小动作，例如延迟发布、减少承诺、引入反对意见。

**适用边界**：- 用户处在明显初创、低能量、无资源阶段，核心问题不是过盛。
- 用户只想获得情绪鼓励。
- 用户需要精确财务或法律结论。

## 框架 6：关系诊断

**触发词**：冲突、争端、讼、师、比、同人、联盟、合作、团队、信任、分裂、和解

**要旨**：先判断关系结构（讼师比同人睽解萃中孚），再检查是否有孚有律，给出关系动作

**方法论**：《周易》把关系问题分成多种结构：讼是争端，师是组织化动员，比是依附与结盟，同人是共同目标，睽是分歧，解是解除紧张，萃是聚集，中孚是信任核心。

这个 skill 不问“谁赢谁输”作为第一问题，而是先判断关系结构：这是争讼、动员、结盟、共同体、分裂、解散还是聚合？然后检查是否有孚、是否有律、是否需要大人、是否会终凶。

**执行步骤**：

1. **识别关系结构**
   - 完成标准：标注当前是争讼、组织动员、联盟、共同体、分裂、解散或聚合。
2. **检查信任与规则**
   - 完成标准：说明是否有孚、有律、有共同目标、有第三方规则。
3. **判断升级风险**
   - 完成标准：指出继续争、扩大联盟、动员团队是否会进入终凶或无律。
4. **给出关系动作**
   - 完成标准：输出和解、仲裁、立规则、缩小战线、公开结盟、暂不合作或退出。

**适用边界**：- 用户问题完全是个人学习计划或单人效率问题。
- 用户需要法律诉讼策略且缺乏法律专业信息。
- 用户只想查某卦原文。

## 框架 7：修复周期

**触发词**：蛊、剥、复、井、革、鼎、涣、节、修复、改革、旧账、积弊、重构、新制

**要旨**：排定从止血到清旧账到修基础到改革到承载到设边界的修复顺序

**方法论**：《周易》里有一条很清楚的修复链：蛊是积弊要处理，剥是结构剥落不宜扩张，复是及时回到正轨，井是基础设施和公共资源要修，革是改革要等信任成熟，鼎是新秩序必须能承载，涣是涣散后重组，节是重组后设置边界。

这个 skill 帮用户判断：当前是积弊、剥落、复归、修井、改革、立新制，还是节制阶段。它的输出不是“冲一把”，而是修复顺序。

**执行步骤**：

1. **判断损坏类型**
   - 完成标准：区分积弊、剥落、偏离、基础设施失修、改革时机、承载不足、涣散无节。
2. **确定修复阶段**
   - 完成标准：标注当前处在蛊、剥、复、井、革、鼎、涣、节中的哪一段。
3. **排定先后**
   - 完成标准：给出先止血、清旧账、修基础、建立信任、改革、承载、设边界的顺序。
4. **设置复查点**
   - 完成标准：列出改革前和改革后必须检查的 3 个信号。

**适用边界**：- 用户只是短期心情不好，没有系统性损坏。
- 用户需要具体工程方案、法律方案或医疗方案。
- 用户想用周易给改革找神秘背书，而不提供事实。

## 框架 8：尺度节制

**触发词**：小过、大过、小畜、大畜、损、益、规模、承载力、资源、承诺太大、试点

**要旨**：检查目标规模和承载能力是否匹配，把行动降级或升级到合适尺度

**方法论**：《周易》不断区分大小、蓄积、过度、损益和节制。小过不是完全不能做，而是只可小事；大过不是普通压力，而是梁柱弯曲，需要结构性处理；小畜是蓄而未雨，大畜是更强的蓄养；损和益不是简单少和多，而是资源重新配置是否有孚、是否可承载。

这个 skill 用来检查“目标规模”和“承载能力”是否匹配，并把行动降级或升级到合适尺度。

**执行步骤**：

1. **列出目标规模**
   - 完成标准：把用户行动分为小事、中事、大事或涉大川级别。
2. **列出承载资源**
   - 完成标准：检查时间、资金、团队、信任、制度、技术、注意力。
3. **判断尺度错配**
   - 完成标准：说明是小过、大过、小畜、大畜、损、益、节中的哪类问题。
4. **调整行动尺寸**
   - 完成标准：输出缩小试点、蓄积等待、加固结构、减少承诺、增加资源或设置节制。

**适用边界**：- 用户只问是否该行动，不涉及规模。
- 用户要精确财务预算但没有数据。
- 用户要求用周易替代项目管理、工程容量或法律评估。
