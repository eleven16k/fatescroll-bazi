# 从《八字命理学导论》蒸馏的8个可执行命理分析框架

> 来源：《八字命理学导论》陈传焕（cangjie-skill 蒸馏）。用法：按用户问题匹配触发词，只读取并运用命中的 1-2 个框架，勿整篇注入。

## 框架 1：日主旺衰分析框架

**触发词**：日主旺衰、身旺身弱、日主旺还是弱、身旺身弱怎么判断、五行力量平衡、旺衰分析、得令、通根、帮身、克泄耗、扶抑、太强了反而不好、弱一点是不是很差、strength assessment

**要旨**：用“日主旺衰”框架判断核心要素（日干）的力量强弱，据此推导应“扶”还是“抑”。旺衰是一切格局用神分析的底层——判断错了后面全错；旺不一定好弱不一定坏，关键是平衡。

**方法论**：命理中“日主/日干”是核心变量，其力量强弱决定整个系统的状态和策略方向。判断强弱三维度：得令——月令（大环境/主季节）是否支持日主五行，得令则先天占优；得地——地支中有没有同类“根”，有根则底盘稳固；得生——天干中有没有同类或生我者帮扶，有帮则外力加持。三者综合评估后日主要么旺要么弱。
最反直觉处：旺不一定好，弱不一定坏，关键是平衡。日主旺→需“克泄耗”（官杀约束、食伤宣泄、财星消耗）来降温；日主弱→需“生帮”（印星滋养、比劫帮身）来补强。旺衰判断是一切格局、用神分析的底层。

**执行步骤**：

1. 确认日干五行属性（甲乙木/丙丁火/戊己土/庚辛金/壬癸水），明确日干五行。
2. 判断月令通气（得令否）：看月令地支五行是否与日干同类或生日干，同类为得令→旺的基础。
3. 检查地支通根（得地否）与天干帮扶（得生否）：四柱地支有无日干同类或生我者，天干有无比劫印星。
4. 综合判断旺衰：得令+得地+得生为旺（占二亦可）；失令+无根+无帮为弱；三项矛盾时以月令为主要依据，参考通根。
5. 给出策略建议：旺→用克（官杀）泄（食伤）耗（财星）；弱→用生（印星）帮（比劫），明确该扶还是该抑及理由。

**适用边界**：不适用于：需精确量化指标的分析（旺衰是定性框架）；极端气候命局（太寒太燥时调候优先于旺衰，应触发 diaohou-youxian）；天元一气、专旺格等特殊格局（“平衡”反而不是目标，恰恰因极端不平衡而成就非凡）；与五行系统无关的纯流程问题或纯逻辑推理。

## 框架 2：十神取象系统

**触发词**：十神、十神取象、正官代表什么、七杀和正官有什么区别、我的十神是什么意思、十神怎么取象、正官、七杀、食神、伤官、偏印、正财、偏财、六亲、ten gods symbolism

**要旨**：将抽象的五行生克翻译为具体的社会角色和人生功能——十神是命理学最核心的分析工具。以日干为“我”，其他干支按生克分五类、每类分正偏，共十种角色。

**方法论**：十神将“五行生克”（物理语言）翻译为“社会角色”（人生语言）。以日干为“我”，分五大类每类分正偏：克我者=官杀（正官=正当约束→法律/上司/丈夫，七杀=猛烈克伐→权威/灾祸）；生我者=印星（正印=母亲/学业/名誉，偏印=偏门学问/继母）；我生者=食伤（食神=温和才华/口福/子女，伤官=锐利才华/口才/傲气）；我克者=财星（正财=稳定收入/妻子，偏财=流动财富/父亲）；同我者=比劫（比肩=兄弟朋友，劫财=竞争对手）。
正偏之分：异性互动为“正”（温和、正当、持久），同性互动为“偏”（激烈、非正统、突发）。这是精准取象的关键——正官可做丈夫，七杀可能成灾，处理策略完全不同。

**执行步骤**：

1. 确定日干五行与阴阳（甲阳木/乙阴木……）。
2. 对每个目标干支计算十神：判断与日干的关系（克我/生我/我生/我克/同我），再判正偏（异性为正，同性为偏）。
3. 取象翻译：根据十神类型翻译为具体人生角色和功能（如正官=法律/秩序/上司/丈夫，食神=温和才华/口福/子女）。
4. 分析十神组合关系：识别伤官见官、食神制杀、财生官、官杀混杂等组合模式及其含义。

**适用边界**：不适用于：与五行系统无关的问题（十神完全建立在五行生克之上）；纯粹的旺衰力量分析（无需翻译为社会角色时用 riwbiao-wangshuai 即可）；需要精确量化的场景（十神是定性映射，不能替代定量分析）。正偏不分或机械套用（如“见正官就是当官”）是书中警告的失败模式。

## 框架 3：调候优先分析法

**触发词**：调候、调候怎么取、冬月生人需要什么、命局太寒、命局太热、调候优先于旺衰吗、为什么旺衰分析不灵了、调候用神、寒暖燥湿、火暖局、水润局、冬月火寒、夏月火炎、冬天生的八字、climate adaptation

**要旨**：用“调候优先”框架分析命局的环境适配需求——极端气候（太寒太燥）下，环境舒适度优先于力量平衡。调候为急，旺衰次之；调候是独立于旺衰的另一分析维度。

**方法论**：调候法独立于旺衰平衡。核心洞察：命局如人，需要舒适的环境（气候）才能正常发挥——再好的体质（旺衰平衡），处在极端环境（太寒太热）也无法发挥。
操作方法：先看月令气候特征——冬寒（亥子丑月）、夏热（巳午未月）、春湿（寅卯辰月）、秋燥（申酉戌月）；再判断日主需要什么“温度调节”——冬需火暖、夏需水润、湿需燥、燥需润；调候用神优先——即使旺衰分析认为应该克泄，但若克泄会进一步恶化气候，调候需求优先。
气候温和→旺衰为主、调候为辅；气候极端→调候为先、旺衰次之。两者不矛盾，理想下调候用神同时满足旺衰需求，冲突时调候优先。生存环境（温度/湿度）的适配需求优先于内部力量的平衡分析。

**执行步骤**：

1. 判断月令气候特征：确定月令地支→季节气候（亥子丑寒/巳午未热/寅卯辰湿/申酉戌燥/中和）。
2. 判断调候需求：寒→需火暖局；热→需水润局；湿→需土燥或火生土；燥→需水润或金生水。
3. 检查命局中是否有调候用神：有→调候得力；无→调候缺失，命局层次打折。
4. 确定调候与旺衰的优先级：气候极端（冬月/夏月）→调候优先；气候温和（春秋月）→旺衰为主、调候为辅。
5. 给出综合建议：调候用神与旺衰用神一致→最佳；两者矛盾→极端气候从调候、温和气候从旺衰。

**适用边界**：不适用于：气候温和的常规命局（春秋月生人气候适中，调候不是第一优先级，应回到旺衰平衡分析）；与五行系统无关的问题。书中警告：不要过度强调调候而忽视旺衰——调候是独立维度但不是唯一维度，常规命局旺衰才是主轴。

## 框架 4：格局成败判断框架

**触发词**：格局、这是什么格局、格局成没成、成格、败格、救应、用神有没有被破坏、格局层次、伤官佩印、食神制杀、财官双美、杀印相生、善格、不善格、月令透干

**要旨**：用“格局成败救应”框架识别命局“主旋律”（最突出的五行力量组合模式），判断层次高低和命运类型。核心是用神的保护链——被保护则成格（贵），被破坏则败格（贱），有解救则救应（转危为安）。

**方法论**：格局是命局的“主旋律”——最突出的五行力量组合模式，决定命运的类型和层次。
取格方法：以月令为基准（月令是“司令之神”，决定命局基本气候和力量分配），月令地支所藏之干透出到天干，即成格局。
格局分善与不善：善格（正官/财/印/食）天生好→喜保护喜辅助→怕克破；不善格（伤官/七杀/羊刃/建禄月劫）天生带凶→喜制约喜转化→怕无制无化。
成败救应三态：成格=用神被保护（有辅助力量帮用神），格局完整有力→贵；败格=用神被破坏（有力量克破用神），格局残缺受损→贱；救应=用神被破坏但又有字来解救（如伤官见官但印来制伤护官）→转危为安。这条“用神的保护链”就是格局层次的分水岭。

**执行步骤**：

1. 确定月令格局：查月令地支藏干（本气/中气/余气），看是否透出天干，透出者即为格局（如月令寅藏甲丙戊，甲透=建禄格，丙透=食神/伤官格）。
2. 判断格局善恶：正官/财/印/食→善格；伤官/七杀/羊刃/建禄月劫→不善格。
3. 定位用神：善格→用神为格局本身的核心十神（如正官格以正官为用）；不善格→用神为制化不善格的十神（如七杀格以食神为制杀之用）。
4. 检查用神的保护/破坏/救应：有保护（财生官/印护官）→成格；有破坏（伤官克正官/财坏印）→败格；败格后有字解救（印制伤护官）→救应。
5. 评估格局层次：成格且用神有力→层次高；败格无救→层次低；败格有救应→层次中等偏上（先苦后甜）。

**适用边界**：不适用于：未判断旺衰时（格局喜忌建立在旺衰判断之上，不先判旺衰就判格局结论不可靠）；天元一气、专旺格等特殊格局（不适用常规善恶格局分类，需特殊处理）；死守格局名目而忽视气势流通（滴天派认为格局名目只是表象，气势流通才是本质）；不涉及组合模式的纯粹旺衰力量评估。

## 框架 5：宫星互参定位法

**触发词**：宫星互参、宫位、婚姻宫是什么星、哪个宫位有问题、父母宫坐什么、我和父亲关系怎么样、祖业宫、父母宫、夫妻宫、子女宫、年柱、时柱、日支逢冲、配偶、palace and star cross-reference

**要旨**：命局的“GPS 定位系统”——用两条轴线交叉定位人生各领域的状态：横轴宫位（人生领域）×纵轴星神（能量类型）=该领域具体状态。十神是纵轴，宫位是横轴，交叉使用才能精准定位。

**方法论**：宫星互参是命局的“GPS 定位系统”，用两条轴线交叉定位。
横轴——宫位（人生领域）：年柱=祖业宫（祖辈/出身/早年 1-16 岁）；月柱=父母宫（父母/家庭/成长 16-32 岁）；日柱=夫妻宫（日支）+自身宫（日干）（自身和配偶 32-48 岁）；时柱=子女宫（子女/晚年/事业归宿 48 岁后）。
纵轴——星神（能量类型）：十神标注该领域被什么能量占据（正官=秩序/管束，七杀=压力/威胁，正印=庇护/滋养，食神=才华/快乐）。
交叉定位：宫位（领域）×星神（能量）=该领域状态。如月柱坐正印→母缘好得庇护；日支（夫妻宫）坐七杀→配偶强势婚姻有压力，坐正财→配偶贤惠婚姻稳固。
宫位逢冲→变动；逢合→外力介入；逢刑害→纠纷阻碍。

**执行步骤**：

1. 定位目标宫位：祖辈/出身→年柱；父母→月柱；配偶/自身→日柱（日支看配偶）；子女/晚年→时柱。
2. 识别宫位上的星神：查该柱的天干和地支藏干→计算十神。
3. 交叉解读：宫位（领域）×星神（能量）=具体状态（如日支×七杀=配偶性格强势、婚姻有压力）。
4. 检查宫位的刑冲合害：逢冲（该领域有变动）、逢合（外力介入）、逢刑害（纠纷阻碍），判断该领域的变化趋势。

**适用边界**：不适用于：动态运势分析（本 skill 只分析静态命局中的宫位定位，大运流年对宫位的冲击触发需结合 dayun-liunian）；不需要领域定位的纯粹十神分析。宫星互参只是辅助手段，不能单凭宫星互参下结论，需结合旺衰、格局、调候综合判断。

## 框架 6：化凶为吉的制化思维

**触发词**：制化、制化思维、七杀怎么制、杀印相生、食神制杀、伤官合杀、伤官佩印、化凶为吉、凶星、七杀有制、制太过、制不及、怎么化解命局的凶星、危机怎么转化为机会、transformation of threats

**要旨**：将困境、威胁、负面力量转化为正向资源——核心是“不要消灭威胁，要转化威胁”。命局凶星（七杀/伤官/羊刃）携带巨大能量，问题在于它指向你；制化提供制/化/合三条路径把“伤害你”变成“帮助你”。

**方法论**：核心：不要消灭威胁，要转化威胁。命局“凶星”（七杀/伤官/羊刃）携带巨大能量，问题不在能量本身而在它指向你。制化提供三条路径：
路径一·制（克制/约束）——食神制杀：你的输出力量（食神=温和才华）反过来克制威胁（七杀）。要点是制要精准——制太过则威胁消失（贫），制不及则威胁失控（灾），如驯兽压制太狠野兽死、太松失控伤人。
路径二·化（转化/缓冲）——杀印相生：在你和威胁间引入缓冲层（印星=学识/智慧），威胁→生→缓冲层→生→你，敌人力量经转化变成你的养分，如武术“借力打力”。
路径三·合（约束/绑定）——伤官合杀：两个凶星天干五合，叛逆与暴猛互合，两凶互约不再各自为祸，反而合力办事。
共同逻辑：威胁能量守恒——消灭威胁=消灭能量，转化威胁=利用能量。

**执行步骤**：

1. 识别命局中的“凶星”：有无七杀（无制的猛烈克伐）、伤官（无制的锐利锋芒）、羊刃（无制的极端刚烈）。
2. 选择制化路径：有食神/伤官能克七杀→用“制”（食神制杀/伤官合杀）；有印星能在七杀与日主之间通关→用“化”（杀印相生）；凶星之间能互合→用“合”（伤官合杀）。
3. 评估制化力度：制太过→凶星消失致贫；制不及→凶星失控成灾；印太弱化不住杀，印太强杀完全消失。
4. 判断制化结果：制化成功→凶变吉（权柄/成就）；制化失败→凶更凶（灾祸/困顿）。
5. 迁移应用（可选）：将“制/化/合”迁移到现实困境——制=直接控制约束威胁，化=引入缓冲层/中间人转化威胁，合=绑定威胁使之为己所用。

**适用边界**：不适用于：命局没有凶星需要处理时（全是善格且格局成立，用 geju-chengbai 即可）；制化力量不够还强行分析为成格（杀重而制轻，食神制不住七杀，不能说“食神制杀”成立，这是自欺欺人）；纯粹的旺衰克泄调节（旺衰法“克泄”调节强弱，制化思维“制化”转化凶星，目的与逻辑不同）。

## 框架 7：大运流年动态分析法

**触发词**：大运、流年、大运流年、我什么大运好、大运怎么看、流年怎么触发事件、为什么前半生顺利后半生不行、运好不好、什么时候转运、起运、帮身运、克身运、命好不如运好、什么时候是关键期、luck cycle analysis

**要旨**：理解静态命局在时间轴上的展开——命局是静态的“出厂配置”，大运流年是动态的“运行环境”，命运是命与运的交互。核心命题：命好不如运好，时机的力量往往大于先天条件。

**方法论**：命局=静态“出厂配置”，大运=十年运势周期（如手机的操作系统版本），流年=每年年度能量（如当年网络环境）。
核心命题：命好不如运好。好命+好运=最优组合；好命+坏运=大材小用；平命+好运=顺势超常发挥；平命+坏运=雪上加霜。
大运推导规则：从月柱起算；阳男阴女→顺排（甲子→乙丑→丙寅），阴男阳女→逆排（甲子→癸亥→壬戌）；每步大运管十年，天干管前五年主外在/表象（事业/名誉/社交），地支管后五年主内在/实质（健康/家庭/心理）。
触发机制：当大运流年的五行与命局产生刑冲合害时触发事件——帮身运（印比）→身弱者逢之则发；克身运（官杀）→身弱者逢之则灾；冲命局某宫位→该领域有变动（如冲日支=婚恋变动）。

**执行步骤**：

1. 排列大运：从月柱起算，确定顺逆（阳男阴女顺排，阴男阳女逆排），计算起运岁数，列出每步大运的干支和年龄段。
2. 判断每步大运的五行倾向：天干地支对日主是帮（生帮）还是克（克泄耗）；天干管前五年主外在，地支管后五年主内在。
3. 检查大运与命局的刑冲合害：冲某柱→该领域有变动；合某柱→有外力介入；刑害某柱→有纠纷阻碍。
4. 结合流年细化：在目标大运中看每年的流年干支如何与大运命局互动，标注出关键年份。
5. 给出时间轴建议：帮身运→适合进取、扩展；克身运→适合保守、蓄力；冲动期→变动高发，需要准备。

**适用边界**：不适用于：不涉及时间维度的静态命局分析；精确到具体事件/日期的预测（大运流年分析的是趋势和窗口期，不是具体事件预测，“什么时候会结婚”无法精确，只能判断“什么时候是婚恋高发期”）；脱离命局的纯大运分析（大运的意义必须相对于命局来理解）；与命理系统无关的纯时间规划。

## 框架 8：盲派做功理论

**触发词**：盲派、做功、盲派怎么做功、做功效率怎么看、做功理论、为什么格局好但赚不到钱、宾主、体用、合功、制功、化功、墓功、获取能力、四墓库、blind school action theory

**要旨**：独立于传统子平格局的分析路径——不取用神、不论格局，直指更本质的问题：命主有没有获取资源的能力？补足子平格局分析中缺失的“获取能力”维度。格局是潜能，做功是实际能力。

**方法论**：盲派完全独立于传统子平格局——不取用神、不论格局，直指更本质的问题：命主有没有获取资源的能力？
两个核心概念：宾主——定位“谁获取谁”：日柱=主（自己/行动者/获取者），他柱=宾（外部世界/资源来源）。体用——定位“用什么获取什么”：体=日主自身可支配的力量（比劫/印星等），用=目标力量（财星/官杀等想获取的对象）。
做功——体对用的生克作用=获取行为：做功成功（体克用/体合用/体生用得回报）→得财得官；做功失败（用克体/用耗体无制）→破财遭灾。
四种做功模式：合功（合住即得到，如日干合财，比“克”更稳定、一劳永逸）；制功（制住即掌权，如食神制杀）；化功（化敌为助，如印化杀生身）；墓功（控制辰戌丑未四墓库即控制其中资源）。盲派不关心格局名目好不好听，只关心实际获取效率高不高。

**执行步骤**：

1. 定位宾主：日柱（日干+日支）=主（自己）；年/月/时柱=宾（外部世界）。
2. 定位体用：体=日主可支配的自身力量（比劫/印星/日支藏干）；用=目标获取对象（财星/官杀/其他柱可用资源）。
3. 检查做功模式：合功（日柱与财/官有无天干五合或地支六合）；制功（日柱之体是否克制凶星）；化功（有无印星化杀生身）；墓功（日柱是否控制辰戌丑未四墓库）。
4. 评估做功效率：做功成功→获取能力强；做功失败→获取能力弱。
5. 与格局分析对比：格局高+做功强→名实相符、大富大贵；格局高+做功弱→怀才不遇、有潜能无变现；格局一般+做功强→务实能干、以小博大。

**适用边界**：不适用于：需要传统子平格局分析的场景（用户想了解格局层次和命运类型，应使用 geju-chengbai，盲派不取格局）；初学者（盲派高度依赖经验和直觉，“不取用神不论格局”看似简单实则需要更深的洞察力）；需要精确推导的场景（盲派重“象”轻“理”，不如子平法有明确的推导步骤）。盲派与子平是互补关系，非对立。
