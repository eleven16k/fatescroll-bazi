# 报告结构与输出规范

四种推演报告的章节结构，蒸馏自 Fatescroll 线上命书/运书/流年/日运生成契约。语气要求：专业、温和、富有智慧，用传统命理术语但解释清晰。

## 通用规则（所有报告必须遵守）

1. **排盘事实原样引用**：脚本输出的四柱、藏干、十神、五行占比、大运、神煞、紫微星曜宫位均为确定性计算结果，严禁修改、重算或另排。
2. **判断内部依据五框架**（分析思考工具，不新增输出章节）：
   - 日主旺衰：先判日主力量强弱（得令/得地/得势），强则抑、弱则扶——定用神大方向的根基。
   - 十神取象：以日干为我推演十神，把五行生克翻译为社会角色（官=事业约束、印=庇护学业、食伤=才华产出、财=财富欲望、比劫=竞争合作）。
   - 调候优先：冬寒夏燥等极端气候命局，先论调候（取暖去燥），环境适配优先于力量平衡。
   - 格局成败：以月令本气取格，善格（官财印食）喜护喜辅，不善格（杀伤刃劫）喜制喜化；成败看用神保护链。
   - 大运流年：静态命局在动态时间轴展开，大运定十年基调，流年触发具体事象。
3. **吉凶并陈、条件化表述**：用「倾向」「可能」「易有……的时期」，禁用「注定」「一定」。详见 ethics.md。
4. **文末附免责声明**（原文见 ethics.md）。
5. 语言随用户（默认中文）；篇幅按各节要求，不随意增删章节。

## 命书 · 终身格局（一次性的静态命盘深度解读）

```markdown
### 命书 · 终身格局

#### 命盘核心日元
**日元本性**：日主五行属性与基本性格
**性格优势** / **性格劣势** / **命理建议**：各一小节

#### 外在形象于天干
天干透出的性格与外在表现（● 要点式）

#### 深层自我于地支
地支藏干反映的深层性格、潜意识（● 要点式）

#### 五行分布与流通
原样引用脚本五行占比/同类/异类/所缺，分析能量强弱与流转，判断用神与忌神

#### 专题分析
- 事业与财富：职业倾向、财富格局、求财建议
- 婚姻与感情：感情运势、伴侣特征、相处之道
- 学习与成长：天赋才华、学业表现、提升建议
- 身体与健康：体质特点、易弱环节、养生建议（不做医学诊断）
- 幸运颜色：基于喜用神给出颜色/方位等开运参考（表述为心理暗示与文化习俗，非改命手段）
- 神煞点睛：仅解说脚本中实际命中的星，每颗 1-2 句；吉星点倾向不承诺，凶煞只述易发倾向并给一句化解视角，严禁恐吓；收尾说明「神煞为辅、格局五行为本，须结合用神喜忌同参」；全空则注明

（若跑了紫微排盘）结合紫微命盘主星、宫位、格局作为补充维度交叉印证，星曜宫位数据原样引用；紫微不可用时仅以八字论之并说明。
```

## 运书 · 岁运流转（当下时运视角）

```markdown
### 运书 · 岁运流转
1. 日运日签：今日日签，一句命理寄语 + 今日宜/忌各 3-5 词
2. 今日卦象：引用脚本本卦/互卦名称与符号，只报名象不做详解（用户点开追问再展开，详解方法见 references/zhouyi-frameworks.md）
3. 当年年运：
   - 年运寄语：至少两个加粗小标题分点（整体基调/关键机遇/需留意之处），严禁一段散文
   - 年运详析：多个加粗小标题分段（整体运势/事业财运/感情人际/健康提醒/关键月份），每段 2-4 句
   - 年运诗词：四句五言或七言
   - 年运五行：金/木/水/火/土 分值（总和 100）——以流年干支对命局喜忌的作用定量给出，须与详析一致
   - 年运宫位：祖辈宫/事业宫/夫妻宫/子女宫 分值（0-100）
4. 时空地图：对脚本 10 步大运各给运势分（0-100）+ 一句简评；当前大运十年内逐年给流年运势分 + 简评
```

## 年运报告（指定单一年份，同「运书」第 3 节展开）

针对缘主八字详析指定公历年：该年整体运势、关键月份提醒，按年运寄语/详析/诗词/五行/宫位五块输出。

## 日运（指定单日，过去日=复盘、未来日=预测）

```markdown
#### 日运日签：≤4 句寄语，贴切该日干支与缘主日主关系
今日宜 / 今日忌：各 3-5 词
#### 当日详批：300-500 字，围绕该日干支与日主生克（事业/人际/情绪/留意点，分点）
```

## 对话式咨询（不出报告时）

- 单人问事：先核对该缘主已有排盘事实（会话内不重排），再按 bazi-frameworks.md 匹配的框架作答。
- 合婚/双人：两份排盘分别跑脚本，按 references/yuelao-frameworks.md 框架分析，仅评互动关系与相处倾向。
- 六爻/梅花/周易问事：起卦可用「今日卦象」或用户自报卦象，按 references/zhouyi-frameworks.md 断卦。
