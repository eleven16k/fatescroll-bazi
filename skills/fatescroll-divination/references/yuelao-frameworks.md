# 从经典命理典籍蒸馏的6个婚恋分析框架

> 来源：八字合婚方法论 Skill (综合渊海子平/三命通会/滴天髓)。用法：按用户问题匹配触发词，只读取并运用命中的 1-2 个框架，勿整篇注入。

## 框架 1：四柱合婚法

**触发词**：合婚、合不合、八字合、配不配、缘分深浅、般配、在一起、能不能结婚、合适吗、分手、磨合

**要旨**：逐柱对比双方四柱的天干地支生克关系，从根基、门户、夫妻宫、子女四个维度评估婚姻契合度

**方法论**：合婚须逐柱对比，不可只看生肖或单柱就下断语。四柱各有分工：

- **年柱看根基**：年柱代表祖业根基与早年环境。双方年柱天干相生或比和为吉，地支三合、六合为佳。年柱天克地冲者，根基不稳，婚后易受长辈干涉。
- **月柱看门户**：月柱代表家庭背景与性格形成期。月柱相生相合者，门当户对、三观相近。月柱相冲者，性格差异大，易因家庭观念起争执。
- **日柱看夫妻宫**：日柱为合婚核心。日干代表自身，日支为夫妻宫。双方日干最好相生或比和，日支相冲为最忌（夫妻宫被冲，婚姻动荡）。日柱天合地合（如甲子与己丑）为大吉。
- **时柱看子女**：时柱代表子女与晚年。时柱相生相合者，子女缘好、晚年和睦。时柱相冲者，易因子女问题生矛盾。

**四柱综合评分法**：
- 四柱皆合：上等婚，天作之合
- 三合一冲：中等婚，需磨合但有根基
- 二合二冲：下等婚，根基薄弱，须大努力维系
- 三冲一合：不宜结合，纵合难久

注意：四柱合婚只是参考，须结合双方大运流年走势综合判断。若双方大运互补（一方走财运时另一方走官运），即使八字有冲也可调和。

**执行步骤**：

1. **收集双方命盘**：先排出男方和女方的完整四柱（年月日时）。
2. **逐年柱**：对比双方年柱天干地支，判断生克关系（生/比和/克/被克），标注合/冲/刑/害。
3. **逐月柱**：同上，重点关注性格与家庭背景的匹配度。
4. **逐日柱**：这是核心——看日干是否相生比和，日支是否相合或相冲。标注日柱关系等级（天合地合/天比地合/天生地合/天克地冲）。
5. **逐时柱**：对比时柱，关注子女缘。
6. **综合评分**：按四柱综合评分法给出总评（上/中/下/不宜）。
7. **大运交叉验证**：检查双方大运走势是否互补。
8. **给出建议**：结合评分给出具体建议——吉者鼓励，凶者提示风险点与调和方向。

**适用边界**：### 不要在以下情况使用此 skill

- 只有单方八字（合婚须双方命盘对比，缺一不可）
- 用户问的是单身何时遇到另一半（用 spouse-palace 或 peach-blossom）
- 用户问的是感情修复策略（用 emotion-repair）

## 框架 2：夫妻宫分析法

**触发词**：什么时候结婚、婚期、配偶、另一半什么样、对象、姻缘、什么时候遇到、伴侣、另一半、日支、夫妻宫

**要旨**：通过日支（夫妻宫）逢冲逢合逢刑判断婚姻状态，推断配偶特征与婚期

**方法论**：日支为夫妻宫，是八字中判断婚姻最直接的宫位。

**夫妻宫核心法则**：
- **日支逢合**：夫妻宫被合（如日支子被丑合），主婚姻有缘，婚期将至之象。流年或大运来合日支时，常有婚恋之事。
- **日支逢冲**：夫妻宫被冲（如日支午被子冲），主婚姻动荡。原局日支逢冲者，感情多变；大运流年冲日支时，婚姻多波动，严重者离婚分离。
- **日支逢刑**：夫妻宫自刑或被刑（如辰刑辰、午刑午），主婚姻中有暗耗、纠结、纠缠不清之事。
- **日支逢害**：夫妻宫被穿害，主婚姻中有小人作祟或暗中破坏。

**日支藏干看配偶特征**：
- 日支藏正财/正官：配偶端正贤淑，循规蹈矩
- 日支藏七杀/偏官：配偶刚强果断，有魄力但也霸道
- 日支藏食神/伤官：配偶聪明有才华，善于交际
- 日支藏比肩/劫财：配偶个性独立，但也意味着竞争（可能有多角关系）
- 日支藏正印/偏印：配偶慈爱顾家，但也可能过度依赖

**婚期推断法则**：
1. 男命以财星为妻，女命以官杀为夫。
2. 大运流年引动财星（男）或官星（女）时，为婚恋之期。
3. 大运流年合日支时，亦为婚期信号。
4. 桃花星逢合之年（红鸾天喜星动），婚恋之事多。
5. 男命身旺财弱，逢财星大运流年可婚；身弱财旺，须比劫帮身方能成婚。

**执行步骤**：

1. **定位日支**：从命盘日柱取出日支，确认其地支属性。
2. **查原局冲合刑害**：检查日支与年支、月支、时支的关系（冲/合/刑/害/破）。
3. **分析藏干**：看日支所藏天干是什么十神，推断配偶性格特征。
4. **查大运流年**：当前大运是否合日支或引动财星/官星。
5. **判断婚恋阶段**：未婚者判断何时有婚恋之象；已婚者判断婚姻稳定性。
6. **描述配偶特征**：根据日支藏干和十神，描述未来配偶或现有伴侣的性格倾向。
7. **给出建议**：对婚恋时机和方向给出指引。

**适用边界**：### 不要在以下情况使用此 skill

- 用户问的是双方合婚对比（用 hehun-four-pillar）
- 用户问的是桃花异性缘（用 peach-blossom）
- 没有命盘（日支信息无法获取）

## 框架 3：十神婚恋法

**触发词**：婚姻不顺、离婚、二婚、再婚、克妻、克夫、伤官见官、比劫争财、婚姻危机、感情不好、婚姻稳定、正财、偏财、正官、七杀、伤官、食神、比肩、劫财

**要旨**：男命看财星女命看官星，通过十神格局判断婚姻吉凶趋势，识别婚姻中的危险信号

**方法论**：十神是八字论命的核心工具，婚姻论断首重财星（男）和官星（女）。

**男命看财星**：
- **正财**代表正妻，**偏财**代表情人或偏房。
- 正财旺而逢生：妻子贤惠，婚姻美满。
- 正财弱而受克：妻子体弱或婚姻不顺。
- 比劫旺而克财：兄弟争妻之象，婚姻易有第三者介入，或妻子被夺。
- 财多身弱：命局财星过多但日主太弱，反主不聚财、不聚妻，晚婚为宜。
- 身旺财弱：自身强旺但财星不足，须走财运方能成婚。
- 正偏财混杂：感情复杂，易有三角关系。

**女命看官星**：
- **正官**代表正夫，**七杀（偏官）**代表偏夫或情人。
- 正官旺而逢生：丈夫端正有能力，婚姻稳定。
- 正官弱而受克：丈夫体弱或婚姻不稳。
- **伤官见官**：女命最忌！伤官克正官，主克夫、婚姻破裂、丈夫事业不顺。
- 官杀混杂：正官七杀同现，感情复杂，易有多段感情。
- 身旺官弱：须走官运方能遇良缘。
- 七杀无制：丈夫性情暴烈，婚姻多冲突。

**婚姻凶象识别**：
- 伤官见官（女）：婚姻最大的破坏力，主离婚、克夫。
- 比劫争财（男）：妻星被比劫争夺，主第三者、妻子出轨或离异。
- 夫妻宫被冲：日支逢冲，婚姻根基动摇。
- 七杀攻身无制：配偶强势压迫，婚姻痛苦。

**化解方向**：
- 伤官见官者：宜晚婚，以时间化解；或找能包容的伴侣。
- 比劫争财者：财星须有食伤保护（食伤泄比劫生财），宜找五行中有食伤旺的伴侣。
- 夫妻宫逢冲者：须待冲力过后的合运年方可成婚。

**执行步骤**：

1. **确定性别**：男命以财星为妻，女命以官杀为夫。
2. **定位妻星/夫星**：在命盘中找出正财/偏财（男）或正官/七杀（女），判断其旺衰、位置、是否受克。
3. **检查十神凶象**：逐一排查——伤官见官？比劫争财？官杀混杂？正偏混杂？
4. **评估婚姻格局**：根据财星/官星的状态，判断婚姻的整体趋势（美满/普通/坎坷）。
5. **找出具体风险**：如果有凶象，指出最可能的问题类型（第三者/克配偶/感情多变）。
6. **给出化解方向**：从五行调和、晚婚、择偶方向等角度给出建议。
7. **结合大运判断**：当前大运是否有利婚姻，何时是危险期，何时是转机。

**适用边界**：### 不要在以下情况使用此 skill

- 没有命盘（十神无法计算）
- 用户只是问一般感情问题，不涉及命理分析
- 用户问的是婚恋时机（用 spouse-palace 更合适）

## 框架 4：桃花姻缘法

**触发词**：桃花运、异性缘、桃花、红鸾、天喜、墙内桃花、墙外桃花、外遇、出轨、魅力、吸引力、没人追、脱单、烂桃花、招桃花

**要旨**：通过桃花星查法和红鸾天喜流年推断异性缘强弱、桃花运性质（正桃花/烂桃花）及婚恋时机

**方法论**：桃花星是八字神煞中主异性缘的特殊标记。

**桃花星查法**（以日支或年支为主）：
- 申子辰见**酉**（鸡）——酉为桃花
- 寅午戌见**卯**（兔）——卯为桃花
- 巳酉丑见**午**（马）——午为桃花
- 亥卯未见**子**（鼠）——子为桃花

口诀：申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子。

**桃花性质分类**：
- **墙内桃花**（年支有桃花）：异性缘好，但桃花在年柱（墙内），主夫妻恩爱，婚姻美满。桃花不外泄。
- **墙外桃花**（日支或时支有桃花）：异性缘旺盛但易外溢，主感情多波折，易有外遇或三角关系。
- **正桃花**：桃花与正财/正官同柱，主因异性缘而得正缘良配。
- **烂桃花**：桃花与七杀/伤官同柱，或桃花逢冲逢合，主因感情生灾、破财、名誉受损。

**红鸾天喜星**（婚恋星）：
红鸾主婚恋喜事，天喜主喜庆之事。查法以年支为主：
- 子年红鸾在卯，天喜在酉
- 丑年红鸾在寅，天喜在申
- 寅年红鸾在丑，天喜在未
- 卯年红鸾在子，天喜在午
- 辰年红鸾在亥，天喜在巳
- 巳年红鸾在戌，天喜在辰
- 午年红鸾在酉，天喜在卯
- 未年红鸾在申，天喜在寅
- 申年红鸾在未，天喜在丑
- 酉年红鸾在午，天喜在子
- 戌年红鸾在巳，天喜在亥
- 亥年红鸾在辰，天喜在戌

大运或流年遇红鸾天喜星动时，多有婚恋喜事、恋情发生。

**咸池星**（即桃花的别称）：
咸池又称"败神"，主风流、酒色之事。咸池逢空亡则桃花无力；咸池逢三合则异性缘极旺。

**执行步骤**：

1. **定位桃花星**：根据用户日支（或年支），按查法口诀找出桃花所在地支。
2. **判断桃花位置**：桃花在年柱（墙内）还是日/时柱（墙外）。
3. **分析桃花性质**：桃花与什么十神同柱——正财/正官（正桃花）还是七杀/伤官（烂桃花）。
4. **查桃花逢合逢冲**：桃花逢合主恋情发生，逢冲主桃花散去或感情波动。
5. **查红鸾天喜**：根据年支查红鸾天喜，看当前大运流年是否引动婚恋星。
6. **综合判断**：给出异性缘强弱评价、桃花运性质（正/烂）、婚恋时机。
7. **给出建议**：对烂桃花者提示风险，对正桃花者鼓励把握时机。

**适用边界**：### 不要在以下情况使用此 skill

- 用户问的是双方合婚对比（用 hehun-four-pillar）
- 用户问的是婚姻中的具体矛盾（用 ten-god-marriage）

## 框架 5：生肖合婚速查

**触发词**：生肖、属相、属龙的、属蛇的、属什么、鸡和龙、鼠和马、三合、六合、相冲、相刑、相害、相破、生肖配、属相合不合

**要旨**：根据地支三合六合为吉、冲刑害破为凶的原则，快速评估双方生肖匹配度

**方法论**：生肖合婚是合婚的入门参考，以地支关系为核心。虽不能单凭生肖定吉凶，但可作为快速判断的参考。

**三合（大吉）**：
三合局为最强的合局，三组：
- 申子辰三合水局（猴·鼠·龙）
- 亥卯未三合木局（猪·兔·羊）
- 寅午戌三合火局（虎·马·狗）
- 巳酉丑三合金局（蛇·鸡·牛）

双方生肖属于同一三合局者，性格互补，相处融洽，为上佳搭配。

**六合（吉）**：
六组地支两两相合，力量次于三合：
- 子丑合（鼠·牛）
- 寅亥合（虎·猪）
- 卯戌合（兔·狗）
- 辰酉合（龙·鸡）
- 巳申合（蛇·猴）
- 午未合（马·羊）

双方生肖六合者，相处和谐，互助互补。

**六冲（凶）**：
六组地支相冲，力量对冲，破坏力强：
- 子午冲（鼠·马）
- 丑未冲（牛·羊）
- 寅申冲（虎·猴）
- 卯酉冲（兔·鸡）
- 辰戌冲（龙·狗）
- 巳亥冲（蛇·猪）

生肖相冲者，性格对立，易起冲突，须注意调和。

**三刑（凶）**：
- 寅巳申三刑（虎·蛇·猴）
- 丑戌未三刑（牛·狗·羊）
- 子卯相刑（鼠·兔）
- 辰午酉亥自刑（龙·马·鸡·猪）

生肖相刑者，关系中多有纠结、暗耗、纠缠不清之事。

**六害（小凶）**：
- 子未害（鼠·羊）
- 丑午害（牛·马）
- 寅巳害（虎·蛇）
- 卯辰害（兔·龙）
- 申亥害（猴·猪）
- 酉戌害（鸡·狗）

生肖相害者，关系中易有暗中阻碍、小人作祟。

**综合判断原则**：
- 三合/六合：加分
- 冲/刑/害：减分
- 同时有合又有冲者：做加减抵消。如龙对虎既有相破又有一六合，则基本持平。
- 生肖只是参考之一，真正的合婚须以完整八字四柱对比为准。

**执行步骤**：

1. **确认双方生肖**：根据双方出生年份确定地支（生肖）。
2. **查三合关系**：双方是否属于同一三合局。
3. **查六合关系**：双方生肖是否构成六合。
4. **查相冲**：双方生肖是否相冲。
5. **查相刑**：双方生肖是否相刑。
6. **查相害**：双方生肖是否相害。
7. **综合加减**：合者为加分，冲刑害为减分，同时存在则抵消。
8. **给出生肖匹配评价**：上等（三合/六合）/中等（无合无冲）/下等（冲刑害）。
9. **提醒局限性**：须明确告知生肖只是参考，真正合婚须看完整八字。

**适用边界**：### 不要在以下情况使用此 skill

- 用户已有完整八字命盘（此时应用 hehun-four-pillar 做四柱合婚，而非仅看生肖）
- 用户不知道对方出生年份（无法确定生肖）

## 框架 6：情感修复诊断

**触发词**：感情修复、冷战、吵架、分手了、想挽回、他不爱我了、感情变淡、矛盾、不理解、沟通不了、闹矛盾、想分手、怎么办、还爱着、放不下、性格不合、磨合

**要旨**：从八字五行互补/相克角度分析双方性格冲突的命理根源，给出调和方向与修复策略

**方法论**：情感问题的命理根源往往在于双方五行的冲突或格局的不匹配。

**五行冲突诊断**：
- **火克金**：一方火旺（急躁、热烈），另一方金旺（刚硬、原则性强）。火炼金过猛则金损，表现为一方不断施压另一方反弹对抗。
- **木克土**：一方木旺（固执、有主见），另一方土旺（包容但被动）。木克土过重则土崩，表现为一方不断要求另一方最终崩溃。
- **土克水**：一方土旺（保守、控制欲强），另一方水旺（自由、流动性强）。土克水过重则水涸，表现为一方过度控制另一方窒息逃离。
- **水克火**：一方水旺（冷静、理性），另一方火旺（热情、感性）。水克火过重则火灭，表现为一方不断浇冷水另一方热情全无。
- **金克木**：一方金旺（果断、直接），另一方木旺（敏感、脆弱）。金克木过重则木折，表现为一方言辞锋利另一方深受伤害。

**调和之道（通关五行）**：
五行相克时，需要"通关"之五行来化解：
- 火克金→用**土**通关（火生土，土生金）：以包容、耐心、稳定来调和
- 木克土→用**火**通关（木生火，火生土）：以热情、表达、沟通来调和
- 土克水→用**金**通关（土生金，金生水）：以理性、规则、边界来调和
- 水克火→用**木**通关（水生木，木生火）：以成长、行动力、共同目标来调和
- 金克木→用**水**通关（金生水，水生木）：以感性、柔和、共情来调和

**比劫过旺型的感情问题**：
命局比劫旺者，自我意识强，在感情中表现为：
- 不愿妥协，坚持己见
- 争强好胜，不肯服软
- 外遇概率高（比劫争财/争夫）

调和方向：须找到能泄比劫的力量（食伤泄比劫），即学会表达情感、体贴对方，而非硬碰硬。

**印星过旺型的感情问题**：
命局印星旺者，过度依赖或过度保护：
- 缺乏安全感，疑心重
- 过度付出导致对方窒息
- 不愿面对现实

调和方向：须找到财星（财破印），即学会独立、自信、有自己的生活重心。

**修复策略框架**：
1. 找到双方五行冲突的根源
2. 确定通关五行
3. 将通关五行的特质翻译成具体行为建议（如"你们的问题是火克金，需要土来调和——土代表包容、耐心、稳定。具体做法是..."）
4. 给出可操作的行动步骤

**执行步骤**：

1. **了解矛盾核心**：引导用户描述当前感情中最主要的矛盾是什么（性格冲突/信任危机/沟通障碍/第三者等）。
2. **五行诊断**：如果双方有命盘，分析双方日主五行的生克关系，找出冲突根源。如果没有命盘，从用户描述的性格特征反推可能的五行冲突类型。
3. **找通关五行**：确定冲突类型后，找到对应的通关五行作为调和方向。
4. **翻译为行为建议**：将抽象的五行调和翻译成具体的、可操作的行为建议（不要说"你们需要土来调和"，而要说"你们需要更多耐心和包容，具体来说..."）。
5. **给出短期和长期建议**：短期急救措施（止损、降温）+长期修复方向（改变相处模式）。
6. **判断修复可能性**：从命理角度诚实评估这段感情是否值得修复，如果命理根基太差，也要温柔但明确地告知。

**适用边界**：### 不要在以下情况使用此 skill

- 用户只是问感情时机（用 peach-blossom 或 spouse-palace）
- 用户问的是是否般配（用 hehun-four-pillar）
- 涉及家暴等严重安全问题时，应优先建议寻求专业帮助而非命理分析
